## Границы лицензии: проект для согласования перед продажами

| Вопрос | Предлагаемое правило |
|---|---|
| Что считается проектом | Одна игра или приложение как отдельный коммерческий продукт, а не один Unity repository |
| Кто может работать | Сотрудники и подрядчики, работающие над этим проектом; без доплаты за seat |
| Платформы | Порты той же игры на другие платформы входят |
| Развитие той же игры | Патчи, локализации и DLC входят, если остаются частью того же продукта |
| Следующая игра | Сиквел и самостоятельный spin-off требуют новой проектной лицензии |
| Исходный код AudioMW | Доступен команде для интеграции и модификации в рамках проекта |
| Распространение игры | Разрешено включение runtime в сборку игры; нельзя перепродавать пакет или выкладывать исходники AudioMW публично |
| Срок | Использование приобретённой версии в этом проекте не истекает |
| Обновления | Предлагается включить обновления текущей major-ветки. Следующая major-версия может быть отдельной необязательной покупкой; старая продолжает работать |
| Поддержка | Канал, срок и SLA определяем перед публикацией. Бессрочное индивидуальное внедрение не включаем в обещание |
| Активация | Без runtime-проверки лицензии, сетевого DRM и блокировки выпущенной игры |

Границы DLC, передачи проекта другому юрлицу, издательских отношений, возвратов и поддержки нужно перенести в окончательные договорные условия до начала продаж. Самостоятельная лицензия не должна случайно ограничить обязательные права покупателя.

## Каналы продаж

На своём сайте планируем проектную лицензию. Для Asset Store остаётся ограничение: стандартная лицензия Extension Asset предусматривает seat-модель. Нестандартные условия допускаются по согласованию Unity; это пока не получено. Нельзя положить свой LICENSE в пакет и считать стандартную EULA заменённой. [Unity EULA](https://unity.com/legal/as-terms), [Submission Guidelines](https://assetstore.unity.com/publishing/submission-guidelines).

План: подготовить точное описание «one project, whole project team, perpetual, no royalties» и запрос на согласование. Запрос пока не отправлен. Если Unity не согласует модель, отдельно выбрать прямые продажи либо другую разрешённую модель магазина. Решение пользователя о проектной лицензии остаётся исходным.

Одинаковая базовая цена сайта и магазина — рабочая коммерческая гипотеза. НДС покупателя, валюта и комиссии могут менять итог checkout. Возможность продавать через оба канала и экономика описаны в market-and-pricing-2026-11-05.md.
