# AudioMW development preview

Unity-native sound events, adaptive music and audio diagnostics.

Install this `.tgz` using Window > Package Manager > + > Add package from tarball.
Open the package's Samples section and import Demo Scene. Open AudioMW Demo.unity
inside the imported sample and enter Play Mode. The demo currently uses synthesized
placeholder audio; real sound-design content and listening approval are pending.

Start with Documentation~/getting-started.md and authoring-and-runtime.md.
Use Window > AudioMW > Audio Browser to find and audition source content, and
Create Sound Event to author an event from selected clips.

This archive is a development validation artifact. The commercial release,
license text, Asset Store approval and final platform claims are still pending.

For the native Sounds → Inspector → Sound Emitter workflow, see
Documentation~/sound-event-workflow.md.
