# BAD SHIFT · звуки для демо

Первый пакет можно прислать отдельно. Он закрывает маршрут от холодильника через водопровод к вывеске и дороге. Имена событий ниже соответствуют проекту. Имена файлов и количество дублей можно менять.

## 1. Кухня, ванная, двор и улица

| Событие AudioMW | Что подготовить | Для чего в сцене |
| --- | --- | --- |
| Fridge | Один ровный моно-луп работающего компрессора. Нужны и низ мотора, и различимая середина. Без сигнала дверцы | У холодильника слышен механизм, при отходе уровень падает |
| Sink_Running | Один сухой моно-луп струи в раковине с различимым верхом | Дверь меняет громкость и срез фильтра в движке. Одной записи достаточно для обеих сторон |
| Toilet_Flush | Один смыв с набором воды и естественным окончанием | Длительность клипа задаёт время наполнения и работы насоса |
| Service_Pump | Один механический моно-луп под нагрузкой | Отдельная позиция во дворе. Тембр должен отличаться от холодильника |
| Coffee_Grinding | Один ровный сухой моно-луп жерновов, без разгона и торможения в записи | Вращение ручки меняет pitch и gain одного голоса |
| Neon_Relay_On / Neon_Relay_Off / Window_Neon_Hum | Два отдельных щелчка и один моно-луп горящей вывески | Включение, устойчивый режим и выключение |
| Traffic_Motor / Patrol_Siren | Ровная петля двигателя и отдельная петля сирены, обе моно | Машина движется в Unity. Панораму, приближение и Доплер делает движок |
| Opening_Birds / Closing_Crickets | Два бесшовных стереофона одной улицы, день и ночь | Кроссфейд фонов. Машины и неон идут отдельными источниками |
| MicrowaveBag / MicrowaveRandom | Один общий набор из трёх хорошо различимых сигналов одинаковой субъективной громкости | Слышна разница между Random и Shuffle Bag |

| События | Предлагаемый набор |

## 3. Музыка

| Куда | Что подготовить |
| --- | --- |
| Explore | Короткое интро, базовая петля и синхронный слой пульса |
| Combat | Базовая петля, ритм и бас отдельными синхронными stems |
| Closing_Keys | Самостоятельная ночная петля |
| Dancer_Music_Loop | Моно-луп из переносной колонки танцора. Это позиционный источник внутри уровня |
| Stinger | Короткий музыкальный акцент |

В текущей сцене Explore, Combat и Closing_Keys используют 120 BPM и 4/4. Для каждой композиции экспортируй stems от одного начала такта до одной границы цикла. Укажи BPM, размер и длину в тактах, если предлагаешь другой темп. Для локальных источников удобен mono WAV, для музыки и фонов — stereo WAV. Предпочтительный исходник для монтажа — PCM WAV 48 kHz / 24 bit. Отдельная версия с эффектом комнаты или Доплером не нужна.

Храп босса, сонный зевок танцора, отдельные дверные скрипы и особое звучание второй фазы можно прислать дополнительно. Для них потребуются выделенные игровые триггеры. Для коммерческого демо нужны права на распространение исходных клипов внутри пакета.
